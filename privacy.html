Scope

Local Ledger ("the application") is a private, single-user personal finance application operated by its owner for the owner's own use. The only person whose financial data the application processes is the owner. The application has no customers and is not offered to the public.

Information collected

With the owner's authorization, the application retrieves the following about the owner's own financial accounts through Plaid Inc. ("Plaid"):

  • Account names, types, and the last four digits of account numbers
  • Account balances
  • Transaction history
  • Investment holdings and investment transactions
  • Liability details such as credit card balances

The application never receives, stores, or has access to the owner's bank or brokerage usernames or passwords. Authentication with financial institutions is handled by Plaid and, where the institution supports it, by the institution's own OAuth login.

How information is used

Information is used solely to present the owner's own balances, spending, holdings, cash flow, and net worth over time. It is not used for advertising, profiling, sale, or any purpose beyond the owner's personal financial review.

Where information is stored

All retrieved data is stored on a single computer owned and controlled by the owner, in an encrypted volume. Encrypted backups are kept in the owner's own cloud storage account. No data is stored on any server operated by the application for third parties, and the application exposes no public internet service.

Sharing

The application does not share, sell, rent, or transmit the owner's financial data to any third party. The only external party involved is Plaid, which acts as the data connection between financial institutions and the application. Plaid's handling of data is governed by the Plaid End User Privacy Policy.

Security

  • API credentials and access tokens are stored in the operating system's encrypted credential store, never in configuration files or source code.
  • The computer hosting the application uses full-disk encryption.
  • No inbound network ports are opened for the application. All connections to Plaid are outbound over HTTPS.
  • Full account numbers are not retrieved or stored.

Retention and deletion

Data is retained for as long as the owner chooses to keep historical financial records. The owner can disconnect any institution at any time through the application or through Plaid Portal, after which no further data for that institution is retrieved. Local data can be deleted by the owner at any time.

Children

The application is not directed to, and does not collect information from, anyone under 18.

Changes

Changes to this policy will be posted on this page with an updated effective date.
